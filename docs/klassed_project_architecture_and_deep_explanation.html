1. Executive Summary & Educational Innovation

The Klassed NEET Adaptive Engine is an enterprise-grade psychometric assessment and personalized learning platform engineered specifically for the National Eligibility cum Entrance Test (NEET-UG). Traditional EdTech products suffer from two systemic failures:

  • The Accuracy Paradox: Raw percentages conflate guessing luck with true mastery and fail to reward students tackling high-discrimination items.
  • Cognitive Conflation: Combining response time and accuracy into a single heuristic penalizes deliberate, deep problem-solvers while rewarding impulsive, lucky guessers.

The Klassed Engine decouples student interaction telemetry into two orthogonal operational streams powered by 15 synchronized machine learning, psychometric, and contextual bandit models:

Accuracy Stream (3PL IRT & BKT)

Dynamically calibrates latent student ability (θ) and continuous topic mastery probabilities P(Lt) across all 65 canonical NCERT chapters using Birnbaum's 3-Parameter Logistic Model.

Cognitive Pacing Stream (van der Linden RT)

Models log-normal response time distributions to isolate authentic calculation speed from cognitive fatigue, hesitation traps, and impulsive guessing (<15s) without contaminating ability estimation.

3. Chapterwise PYQ Practice Drills & Official Exam Year Badges

The platform provides tailored student practice workflows built for maximum pedagogical efficacy:

  • Chapterwise PYQ Drill Selector: Students can select Biology, Chemistry, or Physics and pick any of the 65 chapters to practice a 15-question focused adaptive drill (diagnostic_15).
  • Official Exam Year Provenance Badges: Every question features an authentic badge: e.g. NEET 2024, NEET 2021, NEET 2026 Re-NEET in the active exam, results review, and attempt history.
  • Non-Repeating Paper Guarantee: Consecutive papers enforce near-duplicate sibling exclusion and attempted item filtering, allowing up to 49 unique 45-Q mocks and 12 full 180-Q NEET exams.

5. Scalability & Planetary Architecture (Millions/Billions of Students)

Engineered for high-concurrency execution with bounded resource consumption:

  • Stateless JWT Session Vault & Replay Journal: Telemetry is cryptographically signed and stored in client headers (X-Klassed-Journal), enabling multi-account switching and state recovery without database locks.
  • Strict O(1) Memory Capping: Both the LinUCB bandit and feature store employ LRU caches capped at 50,000 active students, ensuring memory consumption stays below 180 MB under heavy load.
  • Write-Behind Debounced Persistence: 0.5s write-behind debouncing aggregates rapid burst attempts into batch disk transactions.
  • Sub-Millisecond Inference SLAs: Individual psychometric calculations run in 0.01–1.30 ms; entire 15-model pipeline completes in under 15 ms.
